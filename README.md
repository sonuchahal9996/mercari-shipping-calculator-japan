# 2026 Mercari Shipping & Net Profit Calculator (フリマ送料Navi)

Open-source parcel size & shipping calculation engine for Mercari Japan (ゆうゆうメルカリ便・らくらくメルカリ便・ネコポス・ゆうパケットポスト).

### 🚀 Production Live Web Application
Official Web Tool: [https://furimaship.com/](https://furimaship.com/)

### Features
- ゆうゆうメルカリ便 vs らくらくメルカリ便の送料・サイズ自動比較
- 郵便ポスト投函（ゆうパケットポスト ¥215）対応
- メルカリ販売手数料10%と実質送料の自動天引き・赤字警告判定
